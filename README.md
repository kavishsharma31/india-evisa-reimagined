# India e-Visa Reimagined

India e-Visa Reimagined is a hackathon proof of concept exploring a clearer, adaptive and recoverable public e-Visa journey. It focuses on explainable policy guidance, save/resume, document preparation, mock payment and scrutiny, visible case status, synthetic ETA output and simulated downstream interactions without claiming to reproduce private government systems.

> [!IMPORTANT]
> **Unofficial and synthetic only.** This prototype cannot submit a visa application, uses no real applicant data and connects to no live government, payment, APIS, biometric or IVFRT system.

## Working method

Work proceeds through one phase and one numbered step at a time. A step advances only after its exit condition is verified, and a new phase requires explicit user approval.

Application code and technology selection begin only after their planned gates have been reached and approved.
